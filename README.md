# CyberSurfer Neon — Synthwave Subway Runner

Retrofuturistic synthwave subway runner with 3-lane dodge mechanics, magnetic coin collect, jetpack vertical boosts, retro audio synthesizer, and reactive CRT scanline canvas rendering.

## Product Highlights
- **Domain**: Game
- **Visual Theme**: Neon Magenta & Cyan Cyberpunk
- **State Persistence**: Browser localStorage & FastAPI microservices
- **Zero-Dependency Web Client**: Works seamlessly on GitHub Pages

## Architecture & Quick Start
```bash
# Run Tests
pytest tests/

# Docker Deployment
docker-compose up -d --build
```
